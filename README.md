A one-image front page for Monday 23 November 2026: "THE WORLD TODAY". Lead story is Nvidia's Jensen Huang reinstated as CEO after 11 days, with shares up 31.5%. Six more illustrated stories (Ukraine's sea drones sinking the Russian corvette Merkury off Libya, COP31 ending with no deal, strikes on Kyiv, the Cikande factory fire, BepiColombo reaching Mercury, the NHS AI breast-screening trial) and six one-line briefs from around the world. Every story was checked against a named news source on the day; the sources are listed at the foot of the image.

The image is drawn entirely in code by `main.py` (pure Python standard library, no network, no clock, no randomness), so two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024 PNG).
